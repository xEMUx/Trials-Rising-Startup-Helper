# Trials Rising Startup Helper

A lightweight Windows utility designed to help launch **Trials Rising** on systems where the game may experience startup issues.

## Requirements

* Windows 10 / Windows 11 (64-bit)
* Ubisoft Connect installed
* Ubisoft Connect must already be signed in
* **"Remember me"** / automatic sign-in is recommended

## How to Use

----------------------------------------------------------------------------------------
| It may happen that Windows Smart App Control blocks this tool.                       |
| If this occurs, temporarily disable Smart App Control in the Windows settings to     |
| run the tool once.                                                                   |
| Afterward, you can enable Smart App Control again.                                   |
----------------------------------------------------------------------------------------

* Watch my Tutorial *

Link: https://youtu.be/IP76ZuDaVj4

1. Open Steam and Ubisoft Connect.
2. Make sure Ubisoft Connect is already signed in.
3. Run `TrialsRisingHelper.exe`.
4. Adjust the **Trigger Interval** if necessary.
5. Click **START**.
6. Wait for Trials Rising to launch.

## Trigger Interval

The required interval can vary depending on your **internet connection, system performance, and Ubisoft Connect startup time**.

The default value is **1.0 second**.

If the game does not start reliably:

* Try a slightly **lower interval** such as `0.7–0.9 seconds`.
* If that does not help, try a **higher interval** such as `1.2–1.5 seconds`.
* Different systems and network conditions may require different settings.

## Important

This tool is a **startup workaround** and does not modify the game itself.

The helper does not store, request, or handle your Ubisoft credentials.

If the game does not start, stop the helper, adjust the trigger interval, and try again.

## Configuration

Your settings are automatically saved to:

`%AppData%\TrialsRisingHelper\config.json`
